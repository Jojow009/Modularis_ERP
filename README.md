## 📌 Sobre o Projeto
O **Modularis ERP** é um sistema de gestão empresarial full-stack desenvolvido para otimizar e automatizar processos administrativos, de estoque e de produção. 

Este projeto foi construído com foco em arquitetura escalável e regras de negócio sólidas, simulando demandas reais de empresas e indústrias, reduzindo trabalhos manuais e centralizando dados para tomadas de decisão.

## 🚀 Funcionalidades Principais
* **Gestão de Estoque:** Controle de entradas, saídas e movimentações de insumos.
* **Ordens de Produção:** Acompanhamento do ciclo de vida de produtos (ideal para indústrias/manufatura).
* **Cadastro de Clientes e Fornecedores:** Gestão centralizada de contatos e históricos.
* **Folha de Pagamento:** Processamento e gerenciamento automatizado de salários, benefícios e encargos de funcionários.
* **Transferências Financeiras:** Controle rigoroso de movimentações de valores, repasses e gestão de fluxo de caixa entre contas.
* **Dashboard Administrativo:** Interface intuitiva para visualização de métricas e status de operações.

## 💻 Tecnologias Utilizadas

### Backend (API RESTful)
* **Linguagem:** C#
* **Framework:** .NET (Entity Framework Core)
* **Arquitetura:** Padrão MVC / Repository Pattern
* **Banco de Dados:** PostgreSQL 

### Frontend (Interface de Usuário)
* **Framework:** Next.js / React
* **Estilização:** CSS Modules / Tailwind CSS
* **Integração:** Consumo da API via Fetch/Axios
